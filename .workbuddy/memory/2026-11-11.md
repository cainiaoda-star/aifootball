## 17:30 两处隐患一起修（用户「一起修，抓紧」）

### 一 收盘欧赔取到滚球价（已修，影响面比原先估计大得多）

`GetClosingEuAsync` 原来 `MAX(CASE WHEN IsOpening=0 THEN HomeWin END)`，而 `FbOdds` 是
**原地更新**的当前盘（`MERGE … SET CapturedAt = SYSDATETIME()`）——开赛后继续采样，
`IsOpening=0` 那一行的「终盘」就被滚球价顶掉了。实测：**11,532 场有终盘行，8,330 场（72%）
的 CapturedAt 晚于开赛时刻**。inplay-sample 上线后（每 3 分钟刷在踢的场次）只会更严重。

**新口径三级**：当前行够早（`CapturedAt <= MatchTime`）→ 直接用；开赛后才刷新 →
退回 `FbOddsHistory` 里**开赛前最后一个采样点**；历史也没有 → NULL。
「不知道」比「拿滚球价冒充收盘价」好——调用方对 null 本来有兜底，对「很像收盘价的滚球价」没有。
`freshHours` 对两个分支都生效（否则会出现「当前行太旧被排除、却从历史捞回同样旧的那版」）。

近 3 天回查：875 场里 96 场受影响，**96 场全部由历史补回**（0 场变 NULL），
其中 **19 场主胜赔率差 >0.05**。查询耗时无变化（`IX_FbOddsHistory_Match` 覆盖）。
