- ★★ **总进球（JQ）纯模型 Brier 不如「无脑历史频率」**（11-11 验证段 216 场）：历史频率 **.8338** vs 纯模型 **.8425（+1.04%，更差）**，要 w≥.7 才追平；半全场有信息（.8316 vs .8531，−2.51%）。⇒ 「模型有信息」在半全场成立、在总进球**不成立**，别把两者当一个模型看。
- ★★ **混合后必须按玩法全档归一化**（11-11 修，`BlendNormalizer`）：固定水位去水后 Σ市场 实测 .9905（最差 .9582），不归一化则 Σ混合 ≈ 1−.0095w，每档概率与 EV 集体偏低。分母用**全档**、不能用过闸的档（否则闸门自己喂自己）。实测对 ROI 影响 0.000~0.004，属正确性修复、不是收益来源。
- ★★ **权重按玩法给；判据是「市场隐含能不能信」，不是「模型准不准」**（11-11 我写反过被纠正）：档位越少、返奖越高→去水越稳→w 越高。SPF 3 档/.878 最高、BQ 9·JQ 8/.797 中、**BF 31 档/.710 最低**（长尾比例去水高估 + 缺档整场回退）。唯一入口 `MarketWeightFor(playType)`。
- ★★ **安全闸/价值闸必须分开且读不同概率**（11-11）：安全闸=**纯模型** vs 市场（`ModelPctPure` 落库，禁反解，w→1 分母趋零）；价值闸=**混合概率×赔率** ≥ 返奖率×k。旧版合成一条「混合值 vs 市场推导下限」，分子分母同含市场，w 一抬自动松闸。代数：过线 ⇔ 纯模型·赔率 ≥ 返奖率·(k−w)/(1−w)，**k=1 与 w 无关，只有 k>1 才随 w 收紧**。k=1.05 是占位，今日 6 注只砍 1 注且余量 .003 ⇒ **未部署**。
