## 1. 决策前赔率

统计单位：一条 `FbMilkPick`。有轮次的分母是 30（成功 24，失败 6）。没有 `RunId` 的 28 条另计，不能编一个决策时刻。

判定：在 `CapturedAt <= StartedAt` 里取最晚一行。该时刻只有一个赔率、等于注单 `Odds`，并且 `CapturedAt <= MatchTime`，记为唯一匹配。同一时刻多行但赔率相同，记为多条同价。同一时刻赔率不同，记为冲突。没有早于或等于 `StartedAt` 的行、但有更晚的行，记为仅有决策后记录。更早时刻出现过相同价格，不算多条同价。

| 状态 | 唯一匹配 | 多条同价 | 缺失 | 仅有决策后 | 价不符 | 决策前但晚于开赛 |
|---|---:|---:|---:|---:|---:|---:|
| 成功 | 24 | 0 | 0 | 0 | 0 | 0 |
| 失败 | 6 | 0 | 0 | 0 | 0 | 0 |
| 无 `RunId` | 不适用 | 不适用 | 28 条没有决策时刻 | — | — | — |

有轮次的 30 条都能对上一条不晚于开赛的唯一价格。这只说明库存赔率与这条历史一致，不是取价时刻已经被证明。失败轮的 6 条不能因为赔率对上就算发布。

## 只读 SQL

行数来自 `sys.partitions`。索引列来自 `sys.indexes` / `sys.index_columns`。下面语句里的日期和键都限制在奶榜注单上。

赔率分类（30 条有轮次的注；无 `RunId` 的不进这个结果）：

```sql
WITH p AS (
  SELECT pk.PickId, r.Status, r.StartedAt, pk.MatchId, pk.PlayType, pk.OptionCode,
         pk.Odds AS PickOdds, pk.MatchTime
  FROM dbo.FbMilkPick pk
  JOIN dbo.FbMilkRun r ON r.RunId = pk.RunId
)
SELECT p.Status, d.CapturedAt, d.Odds, t.RowCnt, t.DistinctOdds
FROM p
OUTER APPLY (
  SELECT TOP (1) h.Odds, h.CapturedAt
  FROM dbo.FbJcOddsHistory h
  WHERE h.MatchId = p.MatchId AND h.PlayType = p.PlayType AND h.OptionCode = p.OptionCode
    AND h.CapturedAt <= p.StartedAt
  ORDER BY h.CapturedAt DESC
) d
OUTER APPLY (
  SELECT COUNT_BIG(*) AS RowCnt, COUNT(DISTINCT h.Odds) AS DistinctOdds
  FROM dbo.FbJcOddsHistory h
  WHERE d.CapturedAt IS NOT NULL
    AND h.MatchId = p.MatchId AND h.PlayType = p.PlayType AND h.OptionCode = p.OptionCode
    AND h.CapturedAt = d.CapturedAt
) t;
```

实测这 30 条都是 `DistinctOdds = 1`、决策行赔率等于注单、`CapturedAt <= MatchTime`。没有缺失，也没有仅存在决策之后的键。

比分单位（在 3726 行快照内分组，不扫赔率历史）：

```sql
SELECT RunId, MatchId, SUM(ISNULL(ModelPctPure, 0)) AS pureSum
FROM dbo.FbMilkProbSnapshot
WHERE PlayType = N'BF'
GROUP BY RunId, MatchId
HAVING SUM(ISNULL(ModelPctPure, 0)) < 2;
```

满足条件的组是 27 个，展开为 837 行，日期只有 2026-11-14。

榜面：

```sql
SELECT d.SalesDate, d.RunId, d.PickCount, r.StartedAt
FROM dbo.FbMilkRunDate d
JOIN dbo.FbMilkRun r ON r.RunId = d.RunId
WHERE r.Status = N'success'
  AND r.StartedAt = (
    SELECT MAX(r2.StartedAt)
    FROM dbo.FbMilkRunDate d2
    JOIN dbo.FbMilkRun r2 ON r2.RunId = d2.RunId
    WHERE d2.SalesDate = d.SalesDate AND r2.Status = N'success'
  );
```

11-14 的榜面是 `20261114T225008-4408e9`（2 注），11-15 的榜面是 `20261115T084014-3ef1d7`（4 注）。
